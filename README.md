# Retailmu - Frontend

Aplikasi manajemen retail berbasis web yang memungkinkan pengelolaan produk, kategori, supplier, transaksi, dan laporan keuangan secara efisien.

## Tech Stack
- React + TypeScript
- Vite
- TanStack Query
- Tailwind CSS

## Fitur
- Autentikasi berbasis cookie HttpOnly (JWT)
- Protected route & guest route berdasarkan status login
- Role-based access control (administrator, cashier, warehouse)
- CRUD produk, kategori, supplier, penyimpanan, dan transaksi
- Tabel dinamis dengan fitur search, sort, dan pagination
- Form dengan validasi
